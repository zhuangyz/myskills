# Prompt 模板

用户不知道怎么提需求时读。核心：**把形容词翻译成可判定的规格。**

## 为什么形容词无效

| 用户说 | AI 理解成 | 应翻译成 |
|---|---|---|
| 高科技感 | 蓝色渐变 + 发光 | 底色 #05060A，主色 #6D5EFC，光效只两处 |
| 流畅 | 全都淡入 | 入场统一 `cubic-bezier(.22,1,.36,1)`，600ms |
| 有节奏 | 每段一样长 | 四拍 3/4/5/3 秒 |
| 高级克制 | 不知道 | 每屏 ≤3 元素，留白 ≥30%，字重差 ≥300 |
| 有品牌感 | 塞 logo | Logo 只在最后 2 秒出现一次 |

## 三轮对话

### 第一轮：只要规格，不要代码

> 先不要写代码。根据这个需求产出一份 storyboard.md：每个镜头一行，列出起止帧、画面元素、文案、文案时序、素材契约、主体占比、运动与转场；把全部文案登记进 spec.json；再给一份 tokens 草案。我确认后你再动手。

### 第二轮：一次一镜

> 只实现第 2 镜（90–210 帧）。只用已确认的 tokens，不许新增颜色。做完渲染起始帧、中段帧、结束帧三张静帧，并跑一遍自检。

### 第三轮：装配与节奏

> 把镜头串起来，然后只检查三件事：镜头是否短于平台下限、文案是否超平台上限、镜头时长是否均分——跑 `assert.mjs --stage g4 --mp4 out/video.mp4 --sheet`。改完导出。

## 需求翻译表

| 模糊说法 | 追问成 |
|---|---|
| 要高级 | 偏"克制昂贵"还是"冷静精密"？ |
| 快点 | 切点间隔压到 2 秒还是加信息量？ |
| 有质感 | 用实拍素材还是纯图形？ |
| 别太长 | 15 秒还是 30 秒？（必须给数） |
| 要大气 | 大字号 + 大留白，还是宽画幅？ |
| 活泼点 | 加错峰入场还是换圆体？ |
| 像苹果 | 指留白和字重，还是指转场？ |
| 有冲击力 | 前 1 秒给最强画面，还是给声音？ |
| 文艺 | 衬线体 + 慢节奏？ |
| 科技感 | 深色底 + 单色光 + 等宽数字？ |
| 温馨 | 暖色调 + 手写体 + 慢镜？ |
| 干净 | 元素 ≤2 + 纯色背景？ |
| 别太花 | 禁用几种转场？ |
| 有层次 | 前后景分离还是字重分三级？ |
| 像电影 | 遮幅 + 慢推 + 低频音？ |
| 年轻 | 快切 + 亮色 + 无衬线？ |

## 用户说"不好看"时的四问

不要问"你想怎么改"——那等于把工作退回给他。改成四个二分问题：

1. 是**节奏**问题（太快/太慢）还是**内容**问题（说的不对）？
2. 是**看不清**（层级/对比）还是**不想看**（没兴趣）？
3. 是**太满**（元素多）还是**太空**（没信息）？
4. 是**风格**不对（像别的牌子）还是**执行**不对（该对齐的没对齐）？

问完直接给 3 个具体改法让用户点一个，不要给开放式选项。

## 反例：一次要成片的 prompt

> 帮我做一个 15 秒的产品宣传片，要高级、有科技感、节奏流畅，配色好看一点。

这条 prompt 的每一句都在把决定权交给模型的默认值，而默认值就是模板。结果一定是一支"合格但没有作者"的片子。
