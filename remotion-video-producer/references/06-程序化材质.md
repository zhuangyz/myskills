# 程序化材质

环境显得“随意画上去”，多半是因为每个表面只有一种颜色。真实感不来自多边形数量，来自**表面上的不均匀**。

## 铁律

> 不允许纯色面入画。唯一的例外是明确选定的**剪影档位**（背光、远景、景深外的物体）。

一个面要成立，至少要有三层叠加：

| 层 | 频率 | 表现 | 为什么必须有 |
|---|---|---|---|
| 基色变化 | 低 | 明度 ±6–10%，色相偏 ±3° | 消除"塑料纯色"，同材质不同批次 |
| 磨损 | 中 | 边缘发白、转角积垢、踩踏区变亮 | 交代"被使用过" |
| 污渍 / 流痕 | 高 | 竖向水渍、油污斑、接缝积灰 | 交代"在户外" |

只有第一层 = 干净的塑料；三层齐 = 水泥。

## 四个函数（GLSL，可直接抄）

```glsl
// 1) 值噪声 + fbm
float hash(vec2 p){ return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453); }
float noise(vec2 p){
  vec2 i = floor(p), f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);
  return mix(mix(hash(i), hash(i + vec2(1,0)), u.x),
             mix(hash(i + vec2(0,1)), hash(i + vec2(1,1)), u.x), u.y);
}
float fbm(vec2 p){
  float v = 0.0, a = 0.5;
  for (int i = 0; i < 4; i++){ v += a * noise(p); p *= 2.03; a *= 0.5; }
  return v;
}

// 2) 基色变化：同一个材质不会处处一样深
float baseVar = 1.0 + (fbm(uv * 3.0) - 0.5) * 0.16;
vec3 color = baseColor * baseVar;

// 3) 边缘磨损：越靠近边界越脏、越白
float edge = min(min(uv.x, 1.0 - uv.x), min(uv.y, 1.0 - uv.y));
float wear = 1.0 - smoothstep(0.0, 0.12, edge);
color = mix(color, color * 1.25 + 0.04, wear * fbm(uv * 18.0) * uWear);

// 4) 竖向流痕：水渍只往下走，所以把噪声在 y 方向拉长
float streak = fbm(vec2(uv.x * 40.0, uv.y * 3.0));
color *= 1.0 - smoothstep(0.55, 0.85, streak) * uGrime;
```

## three.js 接线：用 onBeforeCompile，不要重写 ShaderMaterial

保留 `MeshStandardMaterial` 的光照与阴影，只往片元着色器里插材质计算：

```ts
const mat = new THREE.MeshStandardMaterial({ color: 0x9a9a94, roughness: 0.9 });

mat.onBeforeCompile = (shader) => {
  shader.uniforms.uWear = { value: 0.6 };
  shader.uniforms.uGrime = { value: 0.45 };
  shader.vertexShader = shader.vertexShader.replace(
    '#include <common>',
    '#include <common>\nvarying vec2 vUv;'
  ).replace(
    '#include <begin_vertex>',
    '#include <begin_vertex>\nvUv = uv;'
  );
  shader.fragmentShader = shader.fragmentShader
    .replace('#include <common>', '#include <common>\nvarying vec2 vUv;\nuniform float uWear, uGrime;\n' + NOISE_GLSL)
    .replace('#include <color_fragment>', '#include <color_fragment>\n  diffuseColor.rgb *= materialTint(vUv, uWear, uGrime);');
};
```

要点：

- **一个材质函数，所有建筑共用**，靠 uniform 调强弱，不要每个物体写一遍
- 尺度参数 `uScale` 必须按物体实际尺寸给，否则 24 米塔台和 3 米围栏的噪声颗粒一样大，一眼假
- 不用贴图，所以不占显存、不用 UV 展开、不用美术资产

## 完成度地板

不是所有物体都要做到三层。**但同一镜头里，相邻两个元素的完成度差不能超过一档**：

| 档 | 表现 | 例子 |
|---|---|---|
| 0 | 纯色 + 无光照变化 | 只允许出现在剪影/远景 |
| 1 | 纯色 + 光照 | 远景建筑轮廓 |
| 2 | 基色变化 | 中景但不在焦点 |
| 3 | 基色 + 磨损 | 中景入焦 |
| 4 | 三层齐 + 尺度正确 | 主体、近景 |

主体做到 4，旁边的机库停在 1 —— 那就是 J-20 那种"贴上去"的观感。

## 检查法（人工，30 秒）

1. 导出**4 张 100% 裁切放大图**：`assert.mjs --zoom`，比在 1080p 全屏里找快得多
2. 每张图里找"能画出边界的纯色块"——不是天空，是物体表面
3. 找到一块，就是一个未处理区域，记一行

## 记录：两个失败的自动指标

试过两次想把这件事量化，都反向，写在这里免得以后重试：

| 指标 | 结果 |
|---|---|
| 全画面 8×8 灰度方差 | J-20 = 42，咖啡 = 12.7。太阳和跑道的大光比让"很空"的画面方差反而更高 |
| 64×36 局部块方差 | J-20 近处跑道 1.2（最低），有贴图的建筑区 20–37。低方差 ≠ 未处理 |

结论：**"未处理"是语义判断，不是像素统计。** 机器只备料（放大图、九宫格），判断必须人来做。
