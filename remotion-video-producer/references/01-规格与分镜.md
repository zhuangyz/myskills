# 规格与分镜

G1 的全部产出。目标只有一个：**在写第一行代码之前，把自由度消灭干净。**

## 一、规格卡（brief.md）

八个字段，缺一个就会有对应部分的失控。

| 字段 | 合格填法 | 不合格填法 |
|---|---|---|
| 画布 | 1080×1920 · 30fps · 15s（450 帧） | 竖屏，十几秒 |
| 给谁看 | 25–35 岁城市白领，刷小红书时看到 | 年轻人 |
| 一句标准 | "别像广告，像记录" | 要高级 |
| 节拍 | 4 拍，时长 3/4/4/4 | 开头中间结尾 |
| 视觉系统 | 见 G2，此处只写调性锚 | 蓝色科技风 |
| 运动语法 | 一个元素一种入场 + 一种微动 | 流畅一点 |
| 信息密度 | 每屏 ≤12 字 | 字别太多 |
| 禁止项 | 纯黑、渐变字、粒子、三种以上字体 | — |

**"禁止项"是性价比最高的一栏。** 模型不知道"高级"是什么，但明确知道"不许发光字叠发光底"。

## 二、节拍表

先有职能，再有镜头。五种通用模型：

| 模型 | 四拍 | 适合 |
|---|---|---|
| 钩子-反差-证明-收口 | 一个动作 / 代价 / 规矩 / 名字 | 品牌片、产品片 |
| 问题-方案-证据-行动 | 痛点 / 解法 / 数据 / CTA | B 端、工具类 |
| 悬念-揭示-放大-落款 | 局部 / 全貌 / 细节 / 品牌 | 新品发布 |
| 倒数清单 | 第 N 名 … 第 1 名 / 品牌 | 榜单、盘点 |
| 单点极简 | 一句话撑全场 | 10 秒以内 |

**四拍时长必须不等。** 3/4/4/4 只是及格，3/4/5/3 才叫有轻重——按字数分配时长会让节奏变平，按职能重量分配才对。

## 三、分镜表（storyboard.md）

六列，缺一列不许进 G3。

| 列 | 内容 | 常见漏项 |
|---|---|---|
| 帧 | 起止帧（不是秒） | 只写秒，实现时换算错 |
| 画面元素 | 图形/图像/装饰，≤3 个 | 把文案算进元素，导致数字虚高 |
| 文案 | 一行一句 | 一镜塞两句 |
| 文案时序 | 第几帧到第几帧入场 | **最容易漏**，导致实现时随便定 |
| 素材契约 | 见下节七项 | 只写"客户提供" |
| 运动与转场 | 一个元素两种动作 | 只写"淡入" |

### 示例（可直接照抄结构）

| # | 帧 | 元素 | 文案 | 文案时序 | 素材契约 | 运动与转场 |
|---|---|---|---|---|---|---|
| 1 | 0–90 | 底光层 / 等宽数字 / 单位 g | 18 克 | 30–55 淡入 | 纯代码生成 | 17.4→18.0，45 帧落定，45–57 阻尼回弹；硬切 |
| 2 | 90–210 | 豆落特写 / 单行字幕 | 多一克，就不是这个味。 | 100–140 逐字，每字 2 帧 | 实拍 Mixkit 16:9 / 23.976fps / 18.7s | 100%→104% 缓推；末 8 帧压黑 |

## 四、素材契约（七项）

只写"谁提供"是不够的。实测：同一图库同一主题的两段素材，一个 1920×1080，一个 1080×1920。

| 项 | 为什么必须写 |
|---|---|
| 谁提供 | 决定 G3 能不能开工 |
| 比例 | 16:9 进 9:16 要裁掉 68% 宽度 |
| 分辨率 | 裁后放大 >1.5× 会明显发软 |
| 时长 | 短于镜头时长要放慢或循环 |
| 帧率 | 23.976 素材进 30fps 时间线，快速动作会重复帧 |
| 主体位置 | 决定能不能裁 |
| 授权 | 商用与否，写进 delivery.md |

## 五、裁切判定

素材进 9:16 前必须回答一个问题：**它是质感还是构图？**

- **质感**（肌理、光影、景深、纹理）→ 可裁，放大也成立
- **构图**（人物、产品、动作关系、空间关系）→ 裁切会毁掉叙事，必须换素材或改版式

实测：豆子特写裁掉 68% 后仍成立，因为它只是肌理；换成手冲壶全景就会裁掉壶嘴和手。

## 六、写作记录

分镜表下面必须附一段"为什么这么定"，每条一行。它的作用不是给别人看，是**逼你把直觉翻译成理由**——翻译不出来的决定，通常就是没想清楚的决定。
