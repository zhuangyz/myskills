# 运动配方

G3 之前读。运动是最容易"看起来花哨但廉价"的部分。

## 三条底层规则

1. **一个元素最多两种动作**：一种入场 + 一种持续微动。第三种就是不自信。
2. **主曲线全片唯一**。混用缓动 = 每个元素都有自己的脾气。
3. **同一时刻只有 1 个元素在做位移**。两个同时动，观众不知道看哪。

## 八个配方

| 配方 | 用途 | 参数 | 禁止用在哪 |
|---|---|---|---|
| 标题三连 | 主标题入场 | 字距 24→0 + 上移 8px + 不透明度 0→1，40 帧 | 副标题（会抢戏） |
| 弹性落定 | 主视觉 / 品牌名 | `spring(damping 200, stiffness 90)`，全片唯一 | 文字段落（抖） |
| 遮罩揭示 | 图文、卡片 | 从一侧 wipe 展开，600ms | 细笔画文字（边缘脏） |
| 数字滚动 | 数据、称重 | 起止值 + `Easing.out(cubic)`，45 帧 | 超过 3 位数（看不清） |
| 视差层移 | 背景、光效 | 前后景位移比 1:0.4，全程 ≤8px | 有文字的前景 |
| 呼吸微动 | 静帧、落款 | 缩放 1.0↔1.015，周期 3s | 需要精确对齐的画面 |
| 逐字显现 | 字幕、口播 | 每字 2 帧，`slice` 截断 | 超过 12 字（等太久） |
| 光扫 | 一次性高光 | 斜 20°，800ms，只出现一次 | 每隔几秒重复（廉价） |

## 节奏曲线

切点密度决定体感：

| 段落 | 适合切点间隔 | 说明 |
|---|---|---|
| 钩子（前 3s） | 2–3s | 太快观众没看懂，太慢划走 |
| 铺陈 | 3–4s | 给信息留时间 |
| 证明 | 2–4s | 可以略快，制造密度感 |
| 收口 | 3–5s | 慢下来，让人记住 |

**四拍时长不要相等。** 3/4/5/3 比 4/4/4/4 有轻重。

## 缓动选择

| 场景 | 曲线 |
|---|---|
| 元素入场 | `Easing.out(Easing.cubic)` |
| 元素退场 | `Easing.in(Easing.cubic)` |
| 位移（大） | `cubic-bezier(.22,1,.36,1)` |
| 数值变化 | `Easing.out(Easing.cubic)` + clamp |
| 物理感 | `spring`（全片最多一处） |

## 死时间

镜头尾部没有运动 ≠ 静止高级，而是"卡住了"。

判定：**连续 ≥15 帧画面完全不变即判负**（0.5s @30fps）。

三种修法，按优先级：

1. 缩短镜头（最干净）
2. 加极慢呼吸（光效透明度 0.16→0.24，位移 0）
3. 让文案晚 10 帧落定

实测：3 秒镜头在 1.9 秒就停住，最后 1.1 秒完全静止，肉眼判断是"播完了"。
