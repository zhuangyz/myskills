# 视觉创意 Prompt 引导者

把「我想做个海边场景」「我想宣传一下这个产品」引导成可逐条验收的详细 prompt。核心理念只有一条：**好 prompt 的每一条都必须可验收**——能对着截图或成片说"有/没有"。引导的目的不是问一堆问题，而是替用户把"可验收细节"问出来。

## 两种产物，两套骨架

| | 可交互 3D 场景 | Remotion 代码视频 |
|---|---|---|
| 成片形态 | 浏览器双击打开，环视/走动 | 渲染出 mp4 / Studio 预览 |
| 实现路径 | Three.js 代码；复杂主体资产可由 Blender 建模导 glTF（资产工厂） | React+TypeScript 时间轴组件 |
| 骨架 | 【风格】【视角与交互】【资产策略】【全景构图】【光照与后期】【动态效果】【要求】 | 【主题与节奏】【视觉风格】【时间轴脚本】【文字与音频】【技术规格】【要求】 |
| 基准样本 | references/spec-template.md（灯塔完整 prompt） | references/video-template.md（组装模板；活样例 `Codex搜索/remotion-promo`，时间轴常量在 src/constants.ts） |

**共用引导内核**（与产物无关）：主题定位 → 时间氛围/色温 → 风格档位 → 内容清单 → 动态元素 → 硬性约束。骨架只决定中段的"专有段"——场景是空间艺术（四向构图、交互结构），视频是时间艺术（镜头脚本、节奏转场）。

## 工作流

### 第 0 步：复述 + 判定产物类型

用一两句复述对想法的理解；**用户没说明要场景还是视频时，必须先问清**（AskUserQuestion：可交互 3D 场景 / Remotion 代码视频，各附一句形态说明）。产物类型决定后续所有问题分支与骨架，不能跳过。

### 第 1 步：引导提问

每轮只问一个问题，用 AskUserQuestion 工具（没有该工具的环境用纯文本选项）。**选项本身就是教学**：每个选项都带具体例子。先问用户要哪种引导模式：
- **A 逐项提问**：一个问题一个问题走，适合想学"好 prompt 长什么样"的用户；
- **B 你提案我修改**：直接产出完整提案（四向构图/时间轴分段），用户增删改，适合"我只要结果"。

问题序列见 `references/question-menus.md`：共用内核 3 问 + 场景分支 / 视频分支。规则：
- 用户每选一项，**当场翻译成 prompt 语言**复述一句（"清晨 → 暖橙低角度阳光 vs 冷蓝阴影的色温对比"），让用户看到翻译过程；
- 用户自由输入永远优先于菜单；菜单只是脚手架；
- A 模式全程不超过 8 问；用户明显不耐烦时切模式 B 收尾。

### 第 2 步：组装 + 可验收性自检

把答案填进对应骨架，然后逐段自检，**模糊词必须替换**：

| 出现这些词 | 替换成 |
|---|---|
| 优美 / 壮观 / 有氛围 | 具体的光色与元素（"暖橙低角度阳光 + 长投影"） |
| 丰富 / 多一些东西 | 具体清单（"近景：缆桩×2、浮球×4"） |
| 大概 / 左右 | 数字（"人眼高度约 1.6m"、"每段 3s"） |
| 生动 / 活起来 | 具体动效清单（每条可截图/可逐帧验证） |

产物附加检查：
- **场景**：四向有空向吗？地平线怎么闭合？资产策略与【要求】段一致吗（混合资产时不能写"不用外部模型"）？
- **视频**：各段时长加总 = 总时长？每段四元组齐全（画面/时长/动效/转场）？叙事有起承转合吗？前后段文字会重叠吗？

### 第 3 步：交付

1. 完整 prompt 放在代码块里输出（六/七段结构，语言风格对齐基准样本：每段开头一句定位，后面分号分隔的短条目）；
2. 提醒：这份 prompt 是自足的——拿去任何 agent / 工具都能用。

## 何时不用本 skill

- 用户已经给出完整结构化需求（各段俱全）→ 不用引导，直接按需使用；
- 非 3D 场景 / 视频领域的需求梳理 → i-have-a-idea。
