# 引导问题菜单

每题给出：问题 → 选项菜单（带例子，直接可用于 AskUserQuestion）→ "翻译复述"示例。菜单是脚手架不是限制，用户自由输入永远优先。先走共用内核 3 问，再按产物类型走分支。

## 共用内核（两条分支都问）

### Q1 主题定位
**问**：创意的核心是什么？给谁看/给谁玩？
**选项**（按用户想法就近给 3-4 个 + Other）：
- 场景类：灯塔渔港、沙漠绿洲、雪山温泉镇、江南水乡…
- 视频类：产品宣传片、概念演绎、情绪短片、活动预告…
**翻译复述示例**：「沙漠绿洲驿站 → 构图核心是'荒凉与生机的对比'」

### Q2 时间氛围/色调（决定光照段与全局色温）
**选项**：
- 清晨：暖橙低角度阳光 vs 冷蓝阴影（日式治愈感最强）
- 正午：高角度白金阳光、高对比、短影
- 黄昏/金色时刻：金红光、长投影、天空渐变最华丽
- 夜晚：自发光为主（窗光/霓虹/月光）
- 特殊天气：雨天（湿反射）、雾天（空气透视）、雪天（覆盖统一色调）
**翻译复述示例**：「黄昏 → 主光金红 0xff9a4d 低角度，天空粉橙→紫蓝渐变，西向表面全部受光」

### Q3 风格档位
**选项**：
- 治愈插画风（日式动画光感）：不卡通不描边、平滑光影、圆角、噪声纹理防纯色
- 写实向：PBR 材质、严格比例、色彩克制
- 科技感/霓虹：深色底+高饱和光效+辉光（视频常用）
- 风格化/低多边形：几何概括、明快色块
**翻译复述示例**：「治愈插画风 → 无描边、阴影偏青高光偏暖的分级」

## 场景分支（可交互 3D 场景）

### S1 站位、视野与走动
**选项**：固定点环视（观景台）/ 小范围走动（栈桥 10-30m）/ 区域内自由走动（几十米）
**默认交互包**（无论选哪个都写入）：拖拽 360° 环视俯仰限幅、滚轮 FOV、WASD 限幅、闲置 5 秒自动环视、页面零 UI、人眼 1.6m。

### S2 资产策略（Blender 资产工厂的接入点）
**问**：场景里的物体怎么来？
**选项**：
- **全程序化生成**：一切用代码生成（噪声纹理+参数化几何）——打开快、种子可复现、零外部依赖；适合自然物（地形/水/树/简单建筑）
- **Blender 混合**：复杂主体（角色、动物、精密机械、雕塑）用 Blender 建模导出 glTF 放进项目，其余程序化——质感上限高，流程多一步建模
**翻译复述示例**：「混合 → 灯塔主体 Blender 建模导出 glTF（含贴图烘焙），地形海水仍程序化；【要求】段相应改写为'主体资产由 Blender 导出 glTF 提供，其余全部程序化生成'」

### S3 四方向构图（工作量最大）
**模式 A（逐向问）**：东南西北各问一轮，选项=该向典型元素菜单。
**模式 B（提案制，默认推荐）**：直接产出四向提案表请用户增删改：

```
北（初始机位）：① ② ③ —— 说出"第一眼看到什么"
东：① ② ③   南：① ② ③   西：① ② ③
远景收边：地平线如何闭合（海平线/沙脊环/山剪影/天穹）
```
提案规则：每向 2-3 个内容点+近/中/远层次；初始机位给最震撼方向；每个点可数可截图（"3 艘渔船"而非"一些船"）；自检空向与场景边缘。

### S4 动效清单（多选，引导到 5-7 条）
按主题定制菜单：水系（波浪/船晃/反光带/浪花/薄雾）、大气（云/风沙流/热浪/雨/萤火）、生物（鸟群/动物/人物活动）、器物（幡旗/光束/灯闪烁/炊烟）。每条写成"主语+动作"。

### S5 特殊要求（可跳过）
**默认硬性七条**（无论如何写入）：经典 script 离线双击可玩 / 种子随机 / 模块分文件 / 零控制台报错 / 页面零 UI / 性能预算 / 素材约束（全程序化="不用外部图片和模型"；混合="主体资产 Blender 导出 glTF，其余程序化"）。

## 视频分支（Remotion 代码视频）

### V1 主线与受众
**问**：这条视频要传达什么？给谁看？
**选项**：产品宣传（卖点递进）/ 概念演绎（一个想法的视觉化）/ 情绪短片（氛围与感受）/ 活动预告
**翻译复述示例**：「产品宣传 → 30 秒内完成'痛点—方案—亮点—行动'的递进，观众是潜在用户」

### V2 时长与节奏
**选项**：
- 15s≈3-4 段：快切卡片式，一段一个冲击点
- 30s≈5-6 段：标准宣传片，有起承转合
- 60s≈7-9 段：叙事型，允许呼吸感慢段
**翻译复述示例**：「30s 起承转合 → 开场 3s 抓注意，中段 2×6s 递进，高潮 5s，收尾 4s 定格」

### V3 风格与文字
- 视觉风格：见共用内核 Q3
- 配色体系：主色/强调色/背景色三色定死（"深蓝底 #0a1420 + 青色强调 #38e1ff + 白字"）
- 字体气质：无衬线现代 / 衬线庄重 / 等宽科技
- 字幕/标语：有没有文字？出现时机？（"每段一句 ≤10 字标语，居中渐入"）

### V4 时间轴脚本（核心段，提案制默认）
直接产出分段表请用户增删改，每段四元组：

```
总时长 30s，共 5 段：
段1 (0-3s)   画面：深色底中一粒光点脉冲    动效：光点放大+粒子汇聚    转场：光扩散吞屏
段2 (3-9s)   画面：…                      动效：…                  转场：…
…
```
提案规则：时长配平（加总=总时长）；每段可独立渲染成图；相邻段有视觉承接（色彩/元素延续）；开场 3 秒内必须出现记忆点。

### V5 文字与音频
- 文字：标题/标语/字幕的文案与进出时机（写进对应段）
- 音频：Remotion 代码内嵌音频需要素材来源；无素材就写明"无音频，纯视觉"——不写虚假的配乐描述

### V6 技术规格
**选项**：横屏 1920×1080 / 竖屏 1080×1920；fps 30 / 60
**默认硬性要求**（无论如何写入）：React+TypeScript 组件化（每段一个组件）/ 时间轴常量集中在一个 constants 文件 / 纯代码生成视觉元素（或声明素材来源）/ 零控制台报错 / `npx remotion studio` 可预览、`npx remotion render` 可出片 / 动效参数种子随机可复现。
