# 视频骨架：Remotion 代码视频

> 本文件是「Remotion 代码视频」的骨架与组装模板；场景骨架见 `spec-template.md`。
> 活样例：`Codex搜索/remotion-promo/`（15 秒科技感宣传片，时间轴常量集中在 src/constants.ts，Studio 3000 端口预览）。

好的视频需求不是"做个宣传片"，而是一份**时间轴级**的可验收规格：每一段画面、时长、动效、转场都可对着成片逐帧检查。用户给的模糊想法由你填满它。

## 六段骨架

```
【主题与节奏】    总时长 / 一句话主线 / 给谁看 / 节奏类型（快切卡片 / 起承转合 / 慢运镜叙事）
【视觉风格】      风格档位 + 三色配色体系（主色/强调色/背景色，色值写死）+ 色彩分级 + 字体气质
【时间轴脚本】    分段表：每段 = 画面内容 + 时长(s) + 动效 + 转场方式；段数按时长（15s≈3-4 段，30s≈5-6 段）
【文字与音频】    标题/标语/字幕的文案与出现时机；音频说明（有素材写来源，无素材写"纯视觉无音频"）
【技术规格】      分辨率（1920×1080 / 1080×1920）/ fps（30/60）/ 组件划分（每段一个组件）
【要求】          工程硬约束（见下）
```

## 组装模板（产出格式）

```
新建一个项目，用 Remotion 做一个「<主题名>」<总时长>秒<横屏/竖屏>视频
（React + TypeScript，代码化生成全部视觉元素）。

【主题与节奏】总时长 <N>s，主线：<一句话>；节奏：<快切/起承转合/慢运镜>，
开场 3 秒内出现记忆点，结尾定格 <收尾方式>。
【视觉风格】<风格档位>；配色：主色 <色值> / 强调色 <色值> / 背景色 <色值>；
<色彩分级描述>；字体 <气质>。
【时间轴脚本】（各段时长加总 = 总时长，任何相邻段有视觉承接）
段1 (0-<n>s)   画面：…  动效：…  转场：…
段2 (<n>-<n>s)  画面：…  动效：…  转场：…
…
【文字与音频】文字：<每段文案与进出时机>；音频：<来源或"纯视觉无音频">。
【技术规格】<分辨率> @ <fps>fps；每段一个组件，时间轴常量集中在一个 constants 文件；
动效参数种子随机，每次渲染结果一致。
【要求】React + TypeScript；视觉元素全部代码生成（或声明素材来源）；零控制台报错；
npx remotion studio 可预览，npx remotion render 可出片；代码按组件分文件逐个写，
每写完一个汇报一句进度。
```

## 自检清单（组装后逐条过）

- **时长配平**：各段时长加总 = 总时长，逐段列出验算；
- **四元组齐全**：每段都有画面/时长/动效/转场，缺一不可；
- **叙事形状**：有开场记忆点（前 3 秒）、中段递进、收尾定格，不是均质的幻灯片；
- **文字不撞车**：相邻段的文字元素在转场时序上不重叠；
- **每段可独立渲染**：任何一段单独截图都能看懂在展示什么；
- **颜色落值**：配色全部是色值，没有"科技蓝"这种模糊词。
