# 参考：门禁与检查命令

每轮交付前必跑。命令按环境替换（`rg`、路径、项目自检命令）。**门禁不是走形式——它是唯一能防住"文档自相矛盾、执行者乱跑"的手段。**

## 0. 通用（每轮）

```bash
# 工作区基线对比：确认没碰会前已有改动
git status --short

# 空白/格式错误
git diff --check
git diff --no-index --check /dev/null "<新文件>" 2>&1 || true
```

## 1. 文档结构门禁

```bash
DIR="CHANGELOGS/<YYYYMM>/<主题>"

# 文档齐备
for f in "$DIR"/01-开发计划.md "$DIR"/02-任务编排器.md "$DIR"/03-流程与状态路由.md \
         "$DIR"/04-多Agent任务执行器.md "$DIR"/05-执行恢复检查点.md; do test -f "$f" || echo "MISSING: $f"; done

# 任务数与编排器一致（示例：8 个任务）
test "$(find "$DIR/tasks" -maxdepth 1 -type f -name 'T*.md' | wc -l | tr -d ' ')" = 8

# 任务编号连续无空号
ls "$DIR/tasks" | grep -o '^T[0-9]\+' | sort -u
```

## 2. 真源覆盖门禁

```bash
# 每个真源标识至少被一个任务覆盖（节点 ID 逐个查）
for node in 3292:17636 3292:17635 3466:20324; do
  rg -q "$node" "$DIR/tasks"/*.md || echo "UNCOVERED NODE: $node"
  rg -q "$node" "$DIR/01-开发计划.md" || echo "NOT IN PLAN: $node"
done
```

## 3. 残留旧命名门禁（合并任务/改名后必跑）

```bash
# 把旧类名、旧路由名、旧任务文件名、旧计数全部列进模式
old_refs=$(rg -n "OldPageName|OldRoute|T05-旧任务名|10 个界面|10个界面" "$DIR" CONTEXT.md || true)
test -z "$old_refs" || { printf '%s\n' "$old_refs"; exit 1; }

# 已删除的任务文件不应再存在
test ! -e "$DIR/tasks/T05-旧任务名.md"
```

## 4. 临时资源门禁

```bash
# 设计工具临时链接绝不能落进文档
! rg -q 'api/mcp/asset|assetPathPrefix|7 天|expires' "$DIR"
```

## 5. 交叉引用门禁

```bash
# 文档内部链接指向的文件都存在
rg -o '\]\(([0-9]{2}-[^)]+\.md)\)' "$DIR" -r '$1' | sort -u | while read -r f; do
  test -f "$DIR/$f" || echo "BROKEN LINK: $f"
done

# 编排器必须能被执行器引用到
rg -q '\[执行恢复检查点\](05-执行恢复检查点.md)' "$DIR/02-任务编排器.md"
rg -q '04-多Agent任务执行器' "$DIR/02-任务编排器.md"
```

## 6. 能力关键词门禁（确认执行器真的写到位）

```bash
rg -q 'fork_turns' "$DIR/04-多Agent任务执行器.md"
rg -q '一次只运行一个' "$DIR/04-多Agent任务执行器.md"
rg -q '所有权令牌' "$DIR/05-执行恢复检查点.md"
rg -q '租约截止时间' "$DIR/05-执行恢复检查点.md"
rg -q '业务阻塞' "$DIR/05-执行恢复检查点.md"
```

## 7. 代码自检（执行阶段，按项目替换）

```bash
dart format --set-exit-if-changed <改动目录>
flutter analyze <改动目录>
flutter test <相关测试>
```

## 8. 收口

- [ ] 变更日志已写（`AICodingChangeLogs/<日期>/<时间>.md` 或项目既有位置）
- [ ] 任务表、任务卡、路由文档、检查点的状态一致
- [ ] 输出交付说明：已完成 / 未完成（含原因）/ 下一步

## 一个自检脚本骨架

```bash
set -e
DIR="CHANGELOGS/<YYYYMM>/<主题>"

fail() { printf 'FAIL: %s\n' "$1"; exit 1; }

test -f "$DIR/01-开发计划.md" || fail "missing plan"
test "$(find "$DIR/tasks" -maxdepth 1 -type f -name 'T*.md' | wc -l | tr -d ' ')" = 8 || fail "task count"
! rg -q 'api/mcp/asset|assetPathPrefix' "$DIR" || fail "temporary asset url"
[ -z "$(rg -n 'OldPageName|OldRoute' "$DIR" || true)" ] || fail "stale naming"
git diff --check -- "$DIR" || fail "whitespace"
printf 'ALL GATES PASSED\n'
```
