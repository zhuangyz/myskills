# 模板：06-任务卡 → tasks/T0N-<名称>.md

> 用法：每个任务一张卡，放在 `tasks/` 下。卡片必须**自包含**——执行它的 subagent 不继承任何会话历史，
> 卡里没写的信息对它等于不存在。
> 完成标准：只给这张卡 + 仓库，一个陌生 Agent 就能独立做完并知道自己做对没有。
