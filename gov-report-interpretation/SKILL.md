# gov-report-interpretation：解读政府报告 + 溯源原文

核心原则只有一条：**文章只是别人的转述，结论必须建立在自己通读原始出处之上。**

一篇"央行发布重要报告"的微信文章 ≠ 央行报告本身。转述层会挑重点、会遗漏、偶尔会讲错。你的价值在于：把原文找出来、读完，然后告诉用户三件事——文章说了什么、原文还有什么、两者哪里不一样。

## 第 0 步：读个人档案

读取本 skill 目录下的 `profile.md`（skill 加载时会显示 base directory）。里面是用户自己维护的背景资料：职业、在做的事、关注的领域。

- 档案存在 → "对你的影响"部分必须结合它来写，挑 3~5 个最相关的角度，无关领域不硬凑。
- 档案缺失或和当前内容对不上 → 先问用户一句（比如"这次主要从哪个角度看：工作收入 / 投资理财 / 生活？"），拿到回答再写，不要瞎编个人化内容。
- 档案是用户亲手维护的：如果用户在对话里说了新的长期背景（换了方向、新增关注点），提醒一句"要不要更新 profile.md"。

## 工作流程

### 1. 获取输入材料

- **网页文章**：优先 webReader（对 `mp.weixin.qq.com` 支持最好，能拿全文）；失败降级 WebFetch；再失败用浏览器自动化读取。微信文章里的图片是 `blob:` 链接，直接忽略。
- **本地文件**：PDF 用 pypdf 提取全文（先查页数）；docx/epub 用对应 skill 或工具处理。
- 外部下载的文件放进独立的新目录（见"落盘"），Python 读取时加 `-I`。

### 2. 识别转述对象

从文章里提取：它解读的到底是**什么**？报告全名、发布机构、发布日期、论文标题、数据来源。

- 常见形态：央行/部委季度报告、政府文件、公司财报、券商研报、学术论文、公告。
- **文章没给出处本身就是一个发现**：明确告诉用户"这篇文章没有给出原始出处"，后续只能基于文章总结，并在输出里标注置信度降级。

### 3. 找到原文

- WebSearch 搜"标题 + 原文/pdf"，优先官方域名（`.gov.cn`、机构官网、公司 IR 页、arXiv/期刊）。
- **核对版本**：标题、日期、发布方要和文章引用的对得上。转载版尤其要防拿错——同名不同季的报告、去年的旧版都遇到过。
- 官方源下载不动时，找可靠转载（如财联社、网易常挂官方 PDF 镜像），下载后核对首页标题和落款。
- 一篇文章引多个出处 → 选主出处精读，其余在"来源"里列出链接。

### 4. 下载与提取

- 新建独立目录，`curl -L` 下载，`file` 验证是真 PDF 而不是错误页。
- pypdf 提取全文到 txt；页数多（>40 页）就分段读，不要试图一次读完。

### 5. 通读原文

- **读完全部内容，不是只读摘要和开头。**这是这个 skill 和普通"总结一下"最大的区别。
- 特别记录：专栏、附录、表格、脚注里的数字和细节——文章没提的部分，往往正是信息增量所在。
- 边读边记两条线：①原文说了什么文章没说的；②原文和文章说法有无出入（出入本身就是值得写进输出的发现）。

### 6. 撰写解读

按下面的固定结构写。对话里完整输出，同时落盘保存（见"落盘"）。

## 输出结构（固定四段式，不限字数）

```
## 这是什么
一两句话定位：谁、发布了什么、为什么值得关注。

## 文章在说什么
转述层要点，3~6 条。

## 原文还说了什么
通读原文后的信息增量：文章没讲的重点、专栏/附录里的数据、与文章说法的出入。
（若原文未能获取，此段改为说明原因 + 置信度降级声明）

## 对你的影响
结合 profile.md，挑 3~5 个最相关的角度；每条说清"为什么和你有关"。
无关的领域不硬凑；宁可少而准，不要多而空。

## 来源
markdown 链接列表：原文、原文章、可靠转载。
```

## 语言硬规则

- **浅显易懂是第一优先。**专业术语第一次出现必须跟一句大白话解释，例如："DR001（银行间隔夜拆借的实时成交价，可以理解为金融圈资金的'批发价'）"。
- **禁止八股文腔。**不写"具有重要意义""稳步推进""纵深发展"这类没有信息量的话；每句话要么有事实、要么有判断。
- **具体数字要保留。**"企业贷款利率约 3%（历史低位）"好于"融资成本处于较低水平"。
- **字数不设限。**"四段"指结构不是篇幅：内容多就写透，内容少就写短。
- 语气像把事情给朋友讲明白，不像写内部简报。

## 边界情况

- **原文付费墙 / 未公开** → 明说，只用文章层总结，标注置信度降低。
- **原文超长（>100 页）** → 至少通读目录 + 摘要 + 每章开头 + 全部专栏/表格；明显与用户无关的章节可略读，但在输出里说明读了哪些、略了哪些。
- **输入本身就是原文**（用户直接给了报告 PDF）→ 跳过第 2~4 步，从第 5 步通读开始。
- **纯观点/评论文章，无原始出处** → 按第 2 步降级处理，第三段写明"无原文可溯源"。

## 落盘

1. 新建任务目录 `解读-<主题短语>/`（放在当前工作目录下）。
2. 下载的原文材料（PDF 等）放进该目录。
3. 解读稿写为 `解读-<主题短语>.md`，放在该目录里，内容与对话输出一致，并在文末注明原文本地路径。
4. 对话里告诉用户文件位置（用 markdown 链接指向 md 文件）。
