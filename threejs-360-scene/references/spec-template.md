# 规格化：六段需求骨架

好的场景需求不是"做个海边场景"，而是一份可逐条验收的规格。写代码前必须先产出这份规格；用户给的模糊想法由你填满它。

## 六段骨架

```
【风格】        画风定位 + 光感参考 + 具体技术约束（描边/材质/圆角/纹理/色温对比）
【视角与交互】  人眼高度 / 环视方式与限幅 / 视野调节 / 走动范围 / 闲置行为 / 无UI
【全景构图】    四个方向（东南西北）逐一列内容清单 + 近/中/远分层 + 地平线闭环要求
【光照与后期】  环境光+主光配方 / 阴影精度要求 / 水面或反射面要求 / 后期链清单
【动态效果】    让场景"活起来"的元素清单（至少 5-7 条）
【要求】        硬性工程约束：程序化生成 / 种子随机 / 性能 / 零报错 / 分文件
```

## 填骨架的方法

**风格段**：从"治愈插画风 / 写实 / 夜景霓虹"等定位出发，翻译成技术语言——不要黑色硬描边、MeshStandardMaterial 平滑光影、物体倒圆角、噪声纹理避免纯色、写明该时段的色温对比（清晨=暖橙朝阳 vs 冷蓝海面；夜景=自发光为主；水下=青色雾）。

**构图段（最关键）**：360° 场景的失败几乎都发生在"某个方向是空的"。逐方向列 2-4 个内容点，并强制：
- 每个方向都有近景细节 + 中景主体 + 远景收边；
- 远景用「海平线 / 山丘剪影 / 天空穹顶」把地平线一圈闭合，任何角度都不能看到场景边缘或空白断面；
- 观察者的站位（栈桥上/岸边/水下）和可走动范围要在此段定死。

**动效段**：对照主题列"活物"——水相关的起伏/浪花/反光带/薄雾、可动物（船晃/海鸥盘游/车流）、光源动画（灯塔光束/霓虹闪烁）、环境粒子。没有这清单，写代码时容易漏成死场景。

**要求段**：固定写死七条硬性规则（见 SKILL.md），再加本项目特有约束。

## 完整示例（灯塔小渔港定稿需求，达标质量的基准样本）

> 新建一个项目，用 Three.js 做一个可直接双击 index.html 打开的「清晨海边灯塔小渔港」360° 沉浸式全景三维场景（离线可运行，经典 script，不用 ES module）。所有文件放在当前目录下新建的「灯塔小渔港」文件夹里。
>
> 【风格】写实偏暖的治愈插画风，参考日式动画电影的柔和光感，画面自然、不卡通：不要黑色硬描边，只靠明暗和色彩区分物体；使用 MeshStandardMaterial 等写实材质，光影平滑过渡，不用硬边色阶；物体边缘倒圆角，避免光滑方块感；礁石有自然起伏，木栈桥、船身、小屋有木纹、锈迹、海水侵蚀等细节；用代码生成噪声纹理（木纹、岩石、沙粒、斑驳墙面），避免大面积纯色；清晨氛围：暖橙的朝阳 vs 冷蓝的海面。
>
> 【视角与交互】观察者站在渔港木栈桥上，人眼高度约 1.6m。鼠标拖拽 / 单指滑动 360° 环视（水平无限制，俯仰限幅）；滚轮调节视野远近；WASD / 方向键可在栈桥和岸边范围内小幅走动（限幅，走不出场景）；静止几秒后视角缓慢自动环视。页面内不要任何 UI：无标题、按钮、提示、水印、加载文字，只有一块全屏画布。
>
> 【全景构图】（四个方向都必须有完整内容，任何角度都没有空白、断面或场景边缘）
> 东：日出方向，开阔海面一直延伸到海平线，朝阳、远处小岛剪影、红绿浮标、出海的渔船。
> 北：突出的岬角礁石上立着红白条纹灯塔（顶部灯室与围栏阳台）和守塔人小屋（亮窗、烟囱），礁石群与浪花。
> 南：渔港海湾，停泊的渔船 ×3、系船桩、防波堤、渔网晾晒架、木箱与浮球、渔具仓库。
> 西：岸边小段沙滩，彩色海边小屋沿山坡排开，松树、电线杆 + 下垂电线、自动贩卖机，身后是起伏的绿色山丘。
> 层次：近景细节丰富，中景是港湾和村落，远景用海平线 + 山丘剪影 + 天空穹顶包住整个场景，地平线一圈闭合。
>
> 【光照与后期】天空环境光 + 低角度暖色朝阳（软阴影，提高阴影精度，不能有条纹瑕疵）+ 环境光遮蔽（AO）；海面要有真实的反光与菲涅尔效果；后期加轻微泛光、远景景深、淡淡的胶片颗粒和暗角。
>
> 【清晨效果】海浪起伏、渔船随浪晃动、灯塔光束旋转、海鸥盘旋、礁石浪花、水面朝阳反光带、贴海面的薄雾、天空从粉橙渐变到浅蓝。
>
> 【要求】所有素材用代码程序化生成，不用外部图片和模型；远景可用低面数简化，近景保证细节；随机数带种子保证每次一致；控制面数和后期开销，保证流畅；零控制台报错。代码按模块分文件逐个写，每写完一个文件汇报一句进度。

注意这份规格的可验收性：每一条都能在截图里检查（"东有朝阳和小岛剪影"、"灯塔有灯室与围栏阳台"）。你生成的规格必须同样可验收——"环境优美"不合格，"东：日出方向 + 远处小岛剪影 + 红绿浮标"才合格。

## 方位约定（所有项目沿用）

`+X=东 / -Z=北 / +Z=南 / -X=西`，初始相机朝东看日出（或主题最震撼的方向）。写进 config.js，评审机位按此约定取。
